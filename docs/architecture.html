How Buddy hears, thinks and answers

Everything below runs on the Pi. No internet, no cloud and no recordings. Each open-source model does one job, and three design choices make Buddy fit small children.

Three ideas worth protecting

Idea 1 · understanding

Matching that grows up with the child

Words are compared as sounds. Changes a child of this age still makes (k→t, r/l→w, dropped end sounds) cost little. Each process stops being tolerated at the age speech-therapy norms say it fades.

tat → cat (age 3.5 ✓, age 8 ✗)

Idea 2 · learning

Quizzes that stay "just hard enough"

Each item moves between five Leitner boxes. Each topic has a level from 1 to 5 that rises when the last four answers were at least 75 % right, and falls when they were 25 % or less. A wrong answer first gets a hint; a second wrong answer gets the answer, told kindly.

Idea 3 · privacy

Nothing leaves, nothing stays

A closed set of sentences is voiced once at setup, so there's no cloud and no speech engine running while the child waits. Audio stays in RAM and is wiped. The learning store holds item IDs only. The mute button closes the microphone stream.
